## 📚 Understanding Your Usage Data

Let's break down what Lancetta shows you so you can make informed decisions:

- **Quota**: This is the number of requests you're allowed to make within a certain time period. Think of it like a monthly data allowance on your phone.
- **Tokens**: A token is a piece of a word that AI models use to understand text. More complex requests use more tokens. Lancetta tracks this so you can see how "expensive" your conversations are.
- **Rate Limits**: This is the speed at which you can make requests. If you hit a rate limit, you might need to wait a few seconds between requests. Lancetta helps you avoid this by alerting you in advance.
